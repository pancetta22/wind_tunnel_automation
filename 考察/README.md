## 主要な結論（2026-06時点）

- 揚力傾斜（±5°）：旧 約3.94/rad、新0605 4.92（1.25×）→ 0608 4.44（1.13×）→ 0610 4.49（1.14×）
- 再マウントで α₀・失速角・Cd0 は旧と一致。**揚力傾斜の残差 1.14× が安定して残る**
- ソフト・較正・ドリフト・整定時間・風速はいずれも棄却済み（シロ）
- 最有力仮説：**マウントのねじれ柔性（空力弾性）** — α₀一致・傾斜のみ過大、手掛け荷重の撓みと整合
- 次の決定打：**同一マウントで風速2点**の傾斜比較（空力弾性なら qが高いほど傾斜急）
