# LCO 解析ガイド（読み方の手引き）

フラッター実験の後処理に追加した **LCO（リミットサイクル振動）非線形動力学解析**
（`--lco` オプション）で出力される図・指標の読み方をまとめる。

参考論文：
- **Trickey et al. (2002)** "The stability of limit-cycle oscillations in a nonlinear aeroelastic system" — 位相図・Poincaré断面・分岐図・スペクトログラムによる応答タイプの分類。
- **Amandolese et al. (2013)** "Low speed flutter and limit cycle oscillations of a two-degree-of-freedom flat plate" — 周波数合流・LCO振幅/位相・成長率。

> **設計方針**：応答タイプ（stable / periodic / quasi-periodic / chaotic）の **自動ラベル付けはしない**。
> 図と数値指標を出力し、**人が目で読み取る**。実データを見てから判定閾値を決める方が堅実なため。

---

## 0. なぜこの解析が必要か

既存の `flutter_analysis.py` は「振動の大きさ（RMS）」「卓越周波数」「フラッター有無」を出すが、
**振動の質**（単純な周期振動か / 準周期か / カオスか）までは区別できない。

論文は、変位を **時間遅れ埋め込み**で位相空間に再構成し、その幾何（ループ・断面・スペクトル）から
応答タイプを見分ける。本系は変位ではなく **6軸力覚センサ（力・モーメント）** を測るので、
**Fy（横力＝プランジ的成分）と Mz（ねじりモーメント）の両方**を観測量として解析する。
変位でなく力・モーメントを使ってよい理論的根拠は **§2.5** を参照（Takens 埋め込みは
「ほぼ任意の観測量」から状態空間を再構成できることを保証する）。

## 2. カルテ図の読み方（`<名前>_lco.png`）

横3列 ×（Fy 上段・Mz 下段）。Trickey の fig.4–7 と同じ並び。

### 列1：時系列
振動波形そのもの。三角波なら周期的、不規則にうねるならカオス的。

### 列2：位相図（時間遅れ埋め込み）
横軸 `x(t)`、縦軸 `x(t-τ)`。τ は自己相関の最初のゼロ交差で自動決定（≈ 1/4 周期）。
**軌道の形で応答タイプが分かる**：

| 見え方 | 応答タイプ | 論文 |
|---|---|---|
| 細い単一ループ（1本の閉曲線） | **periodic LCO** | Trickey fig.4b |
| 2重ループ | period-2 | — |
| 太いリング（トーラス状） | **quasi-periodic** | — |
| 構造を持って広がった塗り | **chaotic** | Trickey fig.6b |

### 列3：パワースペクトル
赤破線が卓越周波数 f0。タイトルに `harm`（調和率）と `flat`（平坦度）。

| 見え方 | 応答タイプ |
|---|---|
| f0 と整数倍（2f0, 3f0…）の離散ピーク | **periodic** |
| 非整数比の2周波数とその和差 | **quasi-periodic** |
| ピークが埋もれ広帯域 | **chaotic** |

## 2.5 なぜ変位βの代わりに Fy / Mz で位相図が成立するのか（重要）

> **よくある疑問**：位相図は本来「変位」と「速度」の2つの状態量で描くもの。論文はフラップ変位 β を使い、
> τ をゼロに近づけると β(t−τ) が速度に対応する、と説明している。では変位ではなく力 Fy・Mz を使うのは、
> その考え方から外れてしまわないか？

**外れません。** 時間遅れ埋め込み（Takens の定理, 1981）が保証しているのは、もっと一般的なことだから。

### ① 「変位でなければならない」わけではない
Takens の定理が言うのは、システムが d 次元のアトラクタ上を動いているとき、
**ほぼ任意の滑らかな観測量** y(t) ひとつから作った遅れ座標 `[y(t), y(t−τ), …]` が、
元の状態空間と幾何的に等価（微分同相）な再構成を与える、ということ。
観測量は変位でも速度でも力でも、システムの動きを反映していて滑らかなら何でもよい。

論文が β（変位）を使ったのは、それが Trickey の実験系で **最も S/N の良い計測量**だったから
（論文 p.2208）であって、変位が理論的に特別だからではない。

### ② Fy / Mz は「変位の代役」ではなく、それ自体が正当な観測量
力・モーメントは、その瞬間のシステムの状態（変位・速度・後流の状態）の関数。
空力モーメント Mz(t) は迎角・ピッチ角速度・プランジ速度・後流などに依存する
＝**システムの状態を反映した観測量**なので、Takens の前提を満たす。
したがって `[Mz(t), Mz(t−τ)]` は「変位と速度の代用」というより、
**Mz という観測窓からシステムのアトラクタを再構成したもの**。再構成された位相図の幾何
（周期=閉ループ / カオス=広がり）は、観測量が変位でも力でも**位相的に同じ**になる。

### ③ 「τ→0 で速度」という説明も、そのまま成り立つ
`Mz(t) − Mz(t−τ) ≈ τ × dMz/dt` なので、遅れ座標の2軸目は実質的に **Mz の変化率**の情報を持つ。
変位の場合の「β とその変化率（≈速度）」と**同じ構造の役割**を、Mz でも果たしている。
「速度の次元を擬似的に作り出す」という働きは、観測量が変位でも力でも等しく機能する。

### ④ 厳密には注意点もある（ただし応答タイプ判定には影響しない）
- 変位 β は「構造の運動」を直接見るが、Fy / Mz は **空力＋構造の合成量**。流体の状態も混ざる。
- 力センサは慣性力・取り付け剛性の影響も拾うため、変位とは違う成分が出ることがある。

これらは「周期的か／カオス的か」という**位相図の定性的な幾何（閉ループか散らばりか）には影響しない**
（その幾何は観測量の選択にロバスト）。本ガイドの目的＝応答タイプ判別には十分妥当。
力センサ特有のノイズが気になる場合は、位相図だけで決めず `loop_thickness` 等の指標と併用する。

> **まとめ**：変位＋速度という古典的な状態空間の発想から「離れた」のではなく、それを Takens が一般化した
> 結果として、変位の代わりに Fy / Mz を使えている。実データでフラッター明瞭点の Mz 位相図がきれいな
> 閉ループになったのは、Mz でも周期的アトラクタが正しく再構成できている証拠。

## 3. Poincaré 断面（指標として `flutter_summary.csv` に反映）

「変位の山（速度ゼロ交差）」をサイクルごとに1点サンプリングしたもの。

| 点群の様子 | 指標 | 応答タイプ |
|---|---|---|
| 1点に集中 | `poincare_disp` 小, `poincare_nclust`=1 | **periodic** |
| 2点 | `poincare_nclust`=2 | period-2 |
| 閉曲線 | `poincare_disp` 中 | **quasi-periodic** |
| 散布 | `poincare_disp` 大 | **chaotic** |

## 3.5 俯瞰図の読み方（条件レベル・全条件レベル）

### 位相図スイープ `phase_sweep_Fy/Mz.png`（条件ごと）
1つの風速条件について、迎角を昇順に並べて位相図をタイル表示する。各セルのタイトルは
`迎角 (thk=ループ太さ)`。**細い閉ループが並ぶ迎角帯＝フラッター（LCO）発生域**、
太い雲＝乱流的（LCO未発生）。迎角を変えると LCO が出たり消えたりする様子が一目で分かる。

### 分岐図 `bifurcation_Fy/Mz.png`（全条件・Trickey fig.3）
横軸=迎角、縦軸=Poincaré断面の値（サイクルごとの山の振幅）。風速ごとに色分け。
- **1本の線（点が縦に集中）** → periodic LCO
- **縦に散らばった帯** → quasi-periodic / chaotic
- 点が0付近にしか無い迎角 → 振動なし（stable）

迎角を横軸にとっているのは、この実験系では迎角が主要な制御パラメータだから
（Trickey は風速を横軸にとる）。

### 周波数合流図 `freq_coalescence.png`（全条件・Amandolese fig.6）
横軸=風速、縦軸=卓越周波数。Fy（○）と Mz（△）を重ねる。連成モードフラッターでは
**2モードの周波数が風速とともに近づく（合流する）**。大きいマーカー＝明瞭なLCO（細いループ）。

### LCO指標マップ `lco_metric_map_Fy/Mz.png`（全条件）
迎角×風速の平面に loop_thickness を色・サイズで重畳。**大きく黄色いマーカー＝明瞭なLCO**
（loop_thickness 小）。フラッター発生域が迎角×風速のどこに広がるかを一望できる。

### 風速版スペクトログラム `spectrogram_speed_*_aoa±NN.png`（全条件・Trickey fig.8）
**迎角を固定**して、横軸=風速・縦軸=周波数・濃淡=PSD[dB]。フラッターが明瞭な迎角でこそ
意味を持つため、`--lco_spec_aoa 18,-20` のように対象迎角を指定する（未指定なら振幅最大の
正側・負側を自動選択）。風速を上げたとき卓越周波数がどう動くか（合流・分岐）を追える。

## 4. CSV に出る指標の意味

`flutter_summary.csv` に `_Fy` / `_Mz` のサフィックス付きで追加される。

| 列 | 意味 | 周期LCO | カオス |
|---|---|---|---|
| `f0_*` | 卓越（基本）周波数 [Hz] | 明確 | 不明瞭 |
| `tau_sec_*` | 埋め込み時間遅れ [s]（≈1/4周期） | — | — |
| `harmonic_ratio_*` | ピークが f0 整数倍に乗る割合（0–1） | **1 に近い** | 低い |
| `spectral_flatness_*` | スペクトル平坦度（0=純音的, 1=広帯域） | **0 に近い** | 大きい |
| `n_incommensurate_*` | f0 整数倍でない強ピーク数 | 0 | — |
| `loop_thickness_*` | 位相図ループの太さ（正規化） | **小** | 大 |
| `poincare_disp_*` | Poincaré点群の散らばり（正規化） | **小** | 大 |
| `poincare_nclust_*` | Poincaré点群の概数クラスタ数 | **1** | 多 |
| `growth_rate_*` | 成長率 ζ（Amandolese eq.6） | **0 付近** | — |

> `growth_rate`（成長率 ζ）：ピーク振幅の対数減衰から算出。**正=発散、負=減衰、0付近=定常LCO**。
> 構造減衰比と直接比較できる。LCO へ収束しているか／発散しているかの判断に使う。

## 5. 応答タイプ 早見表

迷ったらこの順で見る：**位相図 → Poincaré → スペクトル**。

| 応答タイプ | 位相図 | Poincaré (`disp`/`nclust`) | スペクトル (`harm`/`flat`) | RMS時間推移 |
|---|---|---|---|---|
| **stable equilibrium** | ほぼ点（振動なし） | — | ピークなし | ほぼ0で一定 |
| **periodic LCO** | 細い単一ループ | 小 / 1 | 整数倍の離散ピーク（harm≈1, flat≈0） | 一定値に収束 |
| **quasi-periodic** | 太いトーラス | 中 / 1（閉曲線） | 非整数比2周波＋和差 | ゆっくり変動 |
| **chaotic** | 広がった塗り | 大 / 多 | 広帯域（flat大） | 不規則 |

> stable かどうかは、まず既存の RMS / フラッター判定（`flutter_B_*`）で「振動が有意か」を見る。
> 有意な振動があってから periodic/QP/chaotic を上表で見分ける。

## 6. 使い方

```bash
# 全条件を LCO 解析つきで処理
python flutter_analysis.py --base_dir C:/WindyData/260620_flexible --lco

# 1つのCSVだけで素早く動作確認（カルテ図＋指標を出力）
python lco_analysis.py C:/WindyData/.../20260620_..._Pdata_15.01.csv
```

主なオプション：
- `--lco_signals Fy,Mz` … 主軸信号（既定 Fy,Mz）
- `--lco_tau_mode zero_cross|quarter_period` … 時間遅れτの決め方
- `--lco_fmin 1 --lco_fmax 500` … 調和・ピーク解析の帯域
- `--lco_spec_aoa 18,-20` … 風速版スペクトログラムの対象迎角（未指定なら自動選択）

---

## 7. 注意点

- **Poincaré の山検出**は基本周波数 f0 に基づく最小ピーク間隔を使う。f0 が不明瞭な弱い振動では断面が荒れる。
- **τ の自己相関ゼロ交差**が見つからない場合は f0 から 1/4 周期則にフォールバックする。
- 30秒/点・1200Hz の固定長データのため、相関次元や最大リアプノフ指数のような **厳密なカオス指標は今回見送り**。
  上記の実用指標で「目で見分ける」ことを優先している。
- 指標の**閾値（早見表の「小／大」）は実データを見て較正**する前提。現状は自動ラベルを付けない。
