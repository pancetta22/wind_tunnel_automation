# analysis（実験結果の比較・分析）

Windy 新システムの計測結果を過去データと比較するフォルダ。
**このフォルダ内だけで完結**する（過去実験の空力データ・パワポ雛形を同梱）。

## ファイル構成

| パス | 役割 |
|------|------|
| `Windy新システムによる実験結果.pptx` | **比較パワポ（成果物）**。実験を追加すると自動更新される |
| `make_rigid_comparison_local.py` | 比較パワポの生成スクリプト |
| `update_aero_data.py` | 新実験の空力データ取り込み＋パワポ再生成（これ1つ実行すればOK） |
| `aero_data/` | 各実験の空力係数データ（C_aero.csv）の置き場 |
| `研究室MTGテンプレート.pptx` | パワポの雛形（研究室フォーマット） |
| `archive/` | 使い終わった単発の解析スクリプト・旧パワポ・グラフ類 |

## 使い方（新しい実験を比較に追加する）

### 自動（推奨）

名前に **rigid** を含む実験を `run_experiment` で計測すると、後処理の最後に
「過去データと比較しますか？」と聞かれる。**y** と答えるだけで
データ取り込み → パワポ更新まで自動実行される。

### 手動

```
python update_aero_data.py [実験フォルダの親ディレクトリ]
```

- 引数を省略すると `config.json` の `output_dir` を走査する（Windows/Mac 共通）
- 名前に "rigid" を含み `C_aero.csv` を持つフォルダを `aero_data/` へ同期し、
  続けて比較パワポを再生成する
- 新しい実験は**自動検出**され、表・全グラフ（Cl 曲線・偏差・揚力傾斜差など）に反映される

## パワポ内の色分け（3カテゴリ）

| カテゴリ | 色 | 対象 |
|---------|-----|------|
| 旧システム | 青系 | 240521〜260520 の8件（過去平均・min-max帯の母集団） |
| 新システム・接触不良 | 赤橙系 | 260605_1/_2・260608・260610_1 |
| 接触不良修正後／新規 | 緑系 | 260610_2 と今後追加される実験 |

過去平均・min-max帯の母集団は旧システム8件で**固定**されており、
新しい実験を追加しても比較基準はぶれない。

## 経緯メモ（2026-06-10 解決）

- 新システムで揚力傾斜が最大 1.29 倍大きく見えていた真因は
  **差圧デジボル（R6441B）の接触不良**。mV 過小 → 動圧 q 過小 → Cl=L/q が過大。
- 接触修正後の 260610_2（真 mV≈1320, U≈13.1 m/s）で傾斜 0.108/deg ≒ 旧 0.110〜0.112 に一致し解決。
- 零揚力迎角のずれは別問題：**0605 のみ原点パルス 11250**（その他は 11025、差 0.9°）。
- 今後は計測前チェックに「差圧 mV の妥当性確認（デジボル接触）」を行うこと。

詳しい分析の途中経過は `archive/` 内の旧 README・単発パワポを参照。
