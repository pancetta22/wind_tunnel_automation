# 考察（分析・グラフ・スライド）

Windy 自動化システムの計測結果に関する**分析・考察の成果物**を格納するフォルダ。
（実験コード本体 `run_experiment.m` はリポジトリ直下、操作マニュアルは `manual/` に置く）

**このフォルダ内だけで完結**する。過去実験の空力データは `aero_data/` に同梱しており、
研究室フォーマットの比較パワポも外部パスに依存せず再生成できる。

## 自動更新（今後の rigid 実験）

新しく "rigid" を含む名前の実験を計測・後処理（calc_force.py）したら：

```
python update_aero_data.py [実験フォルダの親ディレクトリ]
```

- 探索元（既定: `DEFAULT_SOURCES`、引数で上書き可）から **"rigid" を名前に含み C_aero.csv を持つフォルダ**を探し、`aero_data/` へ同期（新規・変更分のみ）
- 続けて `make_rigid_comparison_local.py` を実行し、`Windy新システムによる実験結果.pptx` を再生成
- 新しい実験は比較スクリプト側で **自動検出**され、表・全グラフに反映（色/マーカー/日付は自動割当、分類は「新規」）。表の行高は件数に応じて自動調整
- 既存の登録済みデータ（伊東/岡本/金光/新Sys/修正後）はスタイル・解説をそのまま維持

## 最終結論（2026-06-10）— 解決

- **揚力傾斜の系統差（最大1.29×）の真因＝差圧デジボルの接触不良**。
  mV過小 → 風速U・動圧q過小 → Cl=L/q が過大 → 傾斜が過大に見えていた。
- 接触修正後の **rigid3（真mV≈1320, U≈13.1 m/s）で 3.87/rad ＝ 旧3.94/rad と一致** → 解決。
  - 研究室指標(AoA_mod)では：旧0.111 → 0605=0.165(異常) → rigid3=0.108(2π・旧域に回復)。
- **α₀のズレは別問題**（取付角）で、再マウントにより旧（0.5〜0.8°）へ収束。α₀は q補正に不変。
- ソフト/ロガー・センサFz較正(おもり0.25%)・定格Limit・後処理・整定時間・三角関数・
  マウントねじれ弾性 は **すべて無罪**と確認済み。
- 今後：計測前チェックに「差圧mVの妥当性確認（デジボル接触）」を追加。
